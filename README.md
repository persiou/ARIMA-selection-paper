# ARIMA selection paper: code

Code accompanying:

> Pérsio Puertas Garcia Lorenti and Daniel Henrique Marco Detzel (2026). Comparison of methods for ARIMA model
> identification.
> DOI: "".

The study compares four ARIMA order selection methods (AIC, BIC, repeated
holdout, and time series cross-validation) on daily streamflow forecasting
at 147 reservoirs of the Brazilian SIN.

## Structure

- `run_experiment.ipynb` — orchestrates the full pipeline.
- `src/` — core modules (data download, selection methods, pipeline,
  statistics, plotting).
- `results/`, `figures/` — outputs (regenerated by the notebook).

## Reproduce

Open `run_experiment.ipynb` and run all cells. Section 2 is the long step
and is checkpointed to `results/selection_results.csv`,
so it resumes safely if interrupted.

Data: daily natural inflow series from the ONS open data portal
(<https://dados.ons.org.br/>, dataset `dados-hidrologicos-res`). Downloaded
automatically by `src/data_api.py`.
